Огнестойкие проходки металлических трубопроводов

Металлические трубопроводы отопления, водоснабжения и технологических сетей проходят через противопожарные стены и перекрытия. Проём заделывается так, чтобы восстановить огнестойкость преграды.

Особенности

  • Подходит для стальных трубопроводов и закладных гильз
  • Учитывает тепловое расширение трубы
  • Совместимо с тепловой изоляцией трубопровода
  • Предел огнестойкости EI 45–180

Решение

Проходы трубопроводов ФП-БУСТ-ПКМ-01 с добровольной сертификацией ГОСТ 30247 закрывают проёмы металлических трубопроводов. Для горючих полимерных труб применяется отдельное решение — противопожарная муфта.

Тепловое расширение трубы

Металлическая труба при нагреве удлиняется и передаёт нагрузку на заделку. Узел проектируют так, чтобы он сохранял целостность и огнестойкость при температурных деформациях трубопровода.

Металл или пластик

Для стальных трубопроводов применяется проходка; для горючих полимерных труб (ПП, ПВХ) — противопожарная муфта. Подскажем правильное решение под материал трубы.

Частые вопросы

Подходит ли проходка для пластиковых труб?

Для металлических — да; для горючих полимерных труб применяют противопожарную муфту.

Учитывается ли изоляция трубопровода?

Да, узел рассчитан на трубопроводы с тепловой изоляцией.
